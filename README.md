# Sistema de Gestão de Sócios - Demo

Este é um sistema completo de gestão de sócios para clubes sociais, desenvolvido como demonstração para clientes.

## 📁 Arquivos do Sistema

- **`index.html`** - Dashboard principal com estatísticas e visão geral
- **`socios.html`** - Gestão completa de sócios (CRUD)
- **`mensalidades.html`** - Controle de pagamentos e mensalidades
- **`carteirinhas.html`** - Emissão e visualização de carteirinhas digitais
- **`espacos.html`** - Gestão de reservas de espaços
- **`agendamentos.html`** - Sistema de agendamentos e calendário
- **`validacao.html`** - Página de validação de QR Code das carteirinhas

## 🚀 Como Usar

1. **Abra qualquer arquivo HTML** em um navegador web moderno
2. **Navegue entre as páginas** usando a barra lateral
3. **Teste as funcionalidades** - todas as páginas são totalmente funcionais

## 🔍 Funcionalidades Principais

### Dashboard (index.html)
- Estatísticas gerais do clube
- Atividades recentes
- Distribuição por planos
- Gráficos visuais

### Gestão de Sócios (socios.html)
- Visualização em cards ou tabela
- Adicionar/editar/excluir sócios
- Filtros por status e plano
- Máscara de telefone automática

### Mensalidades (mensalidades.html)
- Controle de pagamentos
- Estatísticas de arrecadação
- Filtros e busca
- Histórico de pagamentos

### Carteirinhas Digitais (carteirinhas.html)
- Geração de QR codes
- Visualização de carteirinhas
- Impressão
- **Botões de teste** para diferentes tipos de validação

### Validação QR Code (validacao.html)
- **Acesse via URL**: `validacao.html?id=SOC-1`
- Mostra status do sócio
- Status de pagamento
- Foto (iniciais)
- Lista de dependentes
- Timestamp de validação

## 💡 Características Técnicas

- **HTML5 + CSS3 + JavaScript** puro
- **Tailwind CSS** para estilização
- **QRCode.js** para geração de códigos QR
- **Dados mockados** - não requer backend
- **Responsivo** - funciona em desktop e mobile
- **Auto-contido** - abre diretamente no navegador
